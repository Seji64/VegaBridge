# My Routes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a "My Routes" management page with JSON persistence and GPX import/export using MudBlazor.

**Architecture:** Service-based architecture with a dedicated persistence service (`RouteStorageService`) and a conversion service (`GpxService`). UI is implemented as a Blazor page using MudBlazor components.

**Tech Stack:** .NET 10 MAUI Hybrid, MudBlazor, System.Text.Json, System.Xml.Linq.

## Global Constraints
- **UI Framework**: Must use MudBlazor components (Cards, Buttons, Dialogs, etc.).
- **Persistence**: Use individual JSON files in `FileSystem.AppDataDirectory/routes/`.
- **Naming**: Follow existing project naming conventions.
- **Language**: C# 14 / .NET 10.
